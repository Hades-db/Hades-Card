# Hades-Card 🌌

Современный интерактивный сайт-визитка разработчика, выполненный в стиле Bento Grid с анимированным космическим фоном на HTML5 Canvas.

## 🚀 Стек технологий
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
* **Анимация:** HTML5 Canvas API (интерактивные звезды и созвездия)
* **Архитектура:** CSS Grid / Flexbox (Bento-стиль)

## 📦 Особенности проекта
* **Bento Grid:** Плиточный, адаптивный интерфейс для четкого структурирования информации.
* **Interactive Canvas Background:** Динамический космический фон, реагирующий на движение мыши.
* **Dark Theme:** Глубокая темная палитра, подчеркивающая космическую эстетику.
* **Performance:** Чистый код без тяжелых сторонних фреймворков и библиотек.
